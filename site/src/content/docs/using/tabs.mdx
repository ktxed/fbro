Each panel can hold several tabs. A tab remembers its own folder, cursor,
selection, sort order and view mode. The tab bar only appears once a panel has
more than one tab.

There are three kinds of tab:

- **Listing tabs** show a folder, an archive, search results or any other
  [source](../sources/).
- **Terminal tabs** run a shell. See [Terminal](../../viewing/terminal/).
- **Editor tabs** edit a text file inside fbro. See
  [Editing](../../viewing/editor/).

## Open, switch and close tabs

| Action | Keys |
|---|---|
| New tab | <Shortcut id="panel.tab.new" /> |
| Close tab | <Shortcut id="panel.tab.close" /> |
| Next tab | <Shortcut id="panel.tab.next" /> |
| Previous tab | <Shortcut id="panel.tab.prev" /> |

A new tab opens on the same folder as the current tab when that's a folder on
a local disk, and on your home folder otherwise. Next and previous wrap around
at the ends.

With the mouse:

- Click a tab to switch to it.
- Middle-click a tab, or click its **×**, to close it.
- Double-click empty space in the tab bar, or click **+** in the path bar, to
  open a new tab.
- Drag a tab to reorder it within its panel. Press <kbd>Escape</kbd> during the
  drag to cancel. Reordering is mouse-only.

The last tab in a panel can't be closed. An editor tab is the exception: closing
it turns it back into a listing of the file's folder.

Closing a tab you are **not** looking at leaves the visible tab alone — useful
when several tabs show the same folder. Closing the tab you are looking at moves
the panel to the tab on its left, or to the new first tab when it was leftmost.

## Find a tab in a long strip

Once the tabs no longer fit, the strip shows a button with the tab **count** at
its right end. Click it, or press <Shortcut id="panel.tab.list" />, to open a
searchable list of that panel's tabs:

| In the list | Keys |
|---|---|
| Filter by name or path | type |
| Move through the list | <kbd>↑</kbd> / <kbd>↓</kbd>, <kbd>Home</kbd> / <kbd>End</kbd>, <kbd>PgUp</kbd> / <kbd>PgDn</kbd> |
| Switch to the highlighted tab | <kbd>Enter</kbd>, or click the row |
| Close the highlighted tab | <kbd>Delete</kbd> or <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>W</kbd>, or click its **×** |
| Reach a row's **×** by keyboard | <kbd>→</kbd>, then <kbd>Enter</kbd> or <kbd>Space</kbd> closes that tab; <kbd>→</kbd> again walks the **×** down the list |
| Hand the focus back to the search field | <kbd>←</kbd> |
| Close the list, changing nothing | <kbd>Escape</kbd>, or click outside |

Matching letters are marked in the tab name, and each row also shows the folder
or file it points at. Closing an editor tab saves it first, exactly like closing
it from the strip; closing a tab that way leaves the list open, and focus moves
to the **×** of the row beside it. Typing always returns to the search field.
The list appears only in a panel with two or more tabs.

Inside a terminal or editor tab, <Shortcut id="panel.tab.list" /> belongs to the
shell or the editor, so use the count button or the
[command palette](../command-palette/) there.

## Tabs across restarts

fbro restores your tabs when it starts again:

- Listing tabs come back with their folders, sort order and cursor position.
- Editor tabs come back with their files.
- Terminal tabs are not restored.

To restore only the active tab in each panel, turn off **Restore all panel tabs
across sessions** in **Settings → General** (<Shortcut id="app.settings" />).
