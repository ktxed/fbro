<CardGrid>
  <Card title="Two panels, one keyboard" icon="seti:folder">
    Browse two locations side by side and copy, move or compare between them.
    Every action has a shortcut, and <Shortcut id="app.cheat_sheet" /> lists them.
    [Read more](using/navigation/)
  </Card>
  <Card title="Git, terminal and editor" icon="seti:git">
    See git status in the listing, open a terminal tab, edit text in an editor
    tab, and keep scratch notes.
    [Read more](git/repositories/)
  </Card>
  <Card title="bros" icon="puzzle">
    Pass files to a bro (<Shortcut id="panel.pass_to_bro" />) to pack, extract,
    hash, find duplicates, or sync with another machine.
    [Read more](bros/overview/)
  </Card>
  <Card title="Remote fbro" icon="laptop">
    Pair two fbro instances and browse or transfer files between them over SFTP.
    [Read more](remote/pairing/)
  </Card>
  <Card title="Jobs you can interrupt" icon="rocket">
    Copy, move and delete run as background jobs. You can pause, skip or
    cancel them, and fbro asks what to do about each conflict.
    [Read more](files/jobs/)
  </Card>
  <Card title="Archives and search as folders" icon="magnifier">
    Open zip and 7z archives as if they were folders. Search results open in a
    panel and work like any other listing.
    [Read more](bros/archives/)
  </Card>
</CardGrid>
